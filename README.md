"# Resume_Screener" 

I am crating this project to learn and understand more concepts of Machine Learning. 

A decision support system that evaluates resumes against job descriptions using text similarity and rule-based scoring.

## Project Goals
 - Learn applied NLP and ML concepts by building a real-world system
 - Design a clean, explainable resume pipeline.
 - Practice production-style backend development

## Scope
 - Load resume and job description text
 - Perform basic text preprocessing
 - Implement baseline matching logic.

 ## Disclaimer.
 this project is a decision support system only and not a fully automated hiring system.
